# Rage Wars Recompiled - Beta 0.5.0 source kit

This is the matching build/reconstruction kit for the `v0.5.0-beta.1` Windows release. Player setup is in [SETUP.md](../SETUP.md); build instructions are in [PC_RECONSTRUCTION.md](docs/PC_RECONSTRUCTION.md).

Supply your own supported US v1.0 ROM. The kit contains the modified port/runtime/generator source, pinned public dependency recipes, original-byte recovery recipes and complete notices. Generated guest/audio outputs, ROMs, extracted assets, captures, profiles and populated Controller Paks are excluded.

The shipped executable is the selected TESTING binary `7E5E22ABBEDFC8B2B3E1B8C5404B5CB2D8E78A1908FE6C0F158C61C779B1E0A2`. Fresh source-built generators reproduced all 60 pinned game/audio inputs, including 4,537 guest definitions. A new local executable can differ in hash; runtime observations remain tied to the exact binary tested.
